# Naše rodina

Jednoduchý responzivní rodinný web bez závislostí. Stačí otevřít `index.html`
v prohlížeči nebo soubory nahrát na libovolný statický hosting.

## Úprava obsahu

- Texty členů rodiny jsou v `index.html`.
- Barvy, rozložení a responzivní chování jsou v `styles.css`.
- Rok v patičce se doplňuje automaticky v `script.js`.
